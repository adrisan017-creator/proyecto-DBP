# Boletería del Estadio Reales Tamarindos

Sitio web en HTML5, CSS y JavaScript para la venta de boletos del Estadio Reales Tamarindos (Portoviejo).

## Cómo ejecutarlo
1. Abrir esta carpeta en Visual Studio Code.
2. Abrir `index.html` con la extensión Live Server (clic derecho > "Open with Live Server") o con doble clic desde el explorador de archivos.

## Estructura
- `index.html`: calendario de partidos.
- `boletos1.html` a `boletos6.html`: precios y compra de boletos de cada partido.
- `snacks.html`: pedido de comida.
- `registro.html`: formulario de registro con validación.
- `css/estadio.css`: estilos. `js/`: scripts. `img/`: imágenes.
